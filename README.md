reglas para el repositorio (breve recordatorio)
en git bash para poder subir cosas al repo desde la terminal de visual: 
1. acceder a la dirección donde quieren el repo
2. copiar la dirección y ponerla en cd [aquí va tu dirección; sin corchetes]
3. una vez aquí introducir git clone "git@github.com:alanvilchisssss/Compilers_Repository.git"
4. a partir de estos comandos, pueden realizar acciones básicas para subir código o algún archivo que manejen en visual como: 
"git add ." para que, una vez estando seguros de que ya está todo correcto con lo que quieren subir, agreguen para fase de commit 
"git commit -m "comentario de que hicieron en este commit" " 
"git pull" para actualizar estado de los archivos desde el repositorio (IMPORTANTE SIEMPRE REALIZARLO PARA EVITAR CONFLICTOS DE ARCHIVOS O DE VERSIONES)
"git push" para subir cambios
